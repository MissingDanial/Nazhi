# Nazhi Android

纳知 V1 Android 工程骨架。

## V1 范围

- 本地文本保存。
- 分享入口。
- App 内快速输入。
- 悬浮球快捷打开保存面板。
- 今日收件箱。
- 今日回顾。
- 知识条目。
- 本地搜索。
- 一键引用。
- JSON 导出。

V1 不接入云端 AI、语义搜索、语音转文字和短视频模块。

## 打开方式

使用 Android Studio 打开本目录：

```text
.\nazhi-android
```

首次打开后执行 Gradle Sync。当前工程已按 AGP 9.1.0 编写，AGP 9.1 官方兼容 Gradle 9.3.1、JDK 17、API 36.1。
