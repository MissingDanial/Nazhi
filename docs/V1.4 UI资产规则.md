# V1.4 UI 资产规则

**适用版本**：V1.4
**适用工作树**：`nazhi-android-v1.4`
**最后更新**：2026-06-06
**定位**：像素知识农场 UI 改版的资产生成、交付和接入规则

本文随 Android 仓库版本化。表格中的 `asset/as_*` 表示开发工作区的源素材包，当前位于 Android 工作树同级目录 `../asset/as_*`；Android 仓库内版本化的是镜像后的 `app/src/main/res/drawable-nodpi/` PNG 和 Compose 接入代码。

## 1. 基本原则

V1.4 资产只服务 UI 主题改版，不改变数据库、后端接口、AI 整理逻辑、embedding、问答主逻辑、登录、同步或任务系统。

视觉原则：

- 像素风负责情绪和记忆点。
- 正文区域负责阅读和效率。
- PNG 资产负责复杂像素边框、装饰、农田、作物和图标。
- Compose / Material3 负责文字、按钮、表单、长文本、滚动和点击状态。
- 作物点击、选中、内容弹窗继续绑定地块层，不绑定具体作物图片。

不在 PNG 中内嵌中文、数字、状态文案、按钮文字、徽标或水印。所有可变文字都由 Compose 覆盖。

## 2. 目录约定

开发工作区源素材目录：

- `asset/as_2/`：今日页面板、状态标签、公告板、底部导航和设置按钮背景。
- `asset/as_farm/`：农田背景、土地块、选中态覆盖层。
- `asset/as_pl/`：植物三阶段贴图。
- `asset/as_chat/`：问答页消息气泡、输入面板和引用条背景。
- `asset/as_knowledge/`：知识库页搜索面板、筛选面板、条目卡、空状态和状态徽标背景。

Android 接入目录：

- `app/src/main/res/drawable-nodpi/`

交付流程：

1. 新 PNG 先放入对应 `asset/` 子目录。
2. 更新或保留该目录的 `README.generated.md`，说明文件名、尺寸、安全区、锚点和重新生成命令。
3. 将 PNG 镜像复制到 Android `drawable-nodpi/`。
4. 用 hash 或文件尺寸确认源文件与 Android 资源一致。
5. 只改 UI 层代码接入资源，不改业务数据流。

## 4. 安全区和文字覆盖规则

坐标全部按 PNG 原始尺寸从左上角计算。Compose 中按实际渲染比例等比映射，不手动猜位置。

文字覆盖规则：

- 状态标签使用单行短文案，例如 `待整理：1`，不要换行。
- 状态标签文字居中在安全区内。
- 告示牌标题、说明、进度和按钮必须收缩在 `notice_board.png` 的内容安全区内。
- 农场面板标题、图例和农田区域分层布局，不把农田 Canvas 压进标题区。
- 知识库页搜索、筛选、条目卡和空状态内容必须收缩在各自 `knowledge_*.png` 的安全区内。
- 长文本、问答回答、知识条目详情、设置表单不使用像素字体。

调整距离时优先使用 `dp`，不要使用厘米作为实现单位。沟通时可近似换算：

- `0.5cm` 约按 `32dp` 处理。
- `0.8cm` 约按 `50dp` 处理。
- 实际 UI 微调优先以 `8dp` 为步长。

## 5. 农场 Canvas 规则

农场区域采用“固定视窗 + 农田场景整体缩放/拖拽”。

固定的是 Canvas 视窗，不是背景图。以下内容必须属于同一个可变换场景层：

- `farm_field_bg.png`
- 5x5 `plot_soil_empty.png`
- 作物贴图
- `plot_soil_selected.png`
- 异常提示牌或后续农场内装饰

缩放和平移规则：

- 缩放范围保持 `1.0x - 2.2x`。
- 默认比例下，单指滑动交给页面滚动。
- 放大后，单指拖动平移农田场景。
- 缩放回默认比例后，平移归零。
- 平移边界按农田场景尺寸限制，避免视窗露出空白。

点击规则：

- 命中区域以地块矩形和作物近似区域为准。
- 选中态绘制在地块层，不依赖具体作物图。
- 一个地块可以聚合多个 Note / Draft / KnowledgeEntry。

## 6. 生成提示词规则

通用正向要求：

```text
transparent PNG, cozy warm farm-life pixel art, soft green grass, wheat yellow,
warm wood, parchment paper, clay soil accents, hard pixel edges,
chunky stepped corners, blocky shadow, clean readable empty safe areas,
no embedded text, no letters, no numbers, no logo, no watermark
```

通用反向要求：

```text
text, words, numbers, logo, watermark, realistic, smooth vector,
soft gradient, blurry edges, thin lines, crowded decoration,
dark fantasy, neon, sci-fi, copied game asset
```

生成约束：

- 每个素材必须指定精确尺寸。
- 每个需要覆盖文字的素材必须指定安全区坐标。
- 安全区最多允许低对比纸纹、草纹或木纹，不能有高对比装饰。
- 透明素材必须输出 `RGBA`。
- 像素边缘要清楚，不做模糊、柔光、写实质感。
- 不复制任何现有游戏素材，只提炼温暖农场像素感。

## 7. Compose 接入规则

PNG 接入优先使用现有组件边界：

- 状态入口：`NazhiStatusChip`
- 告示牌：`FarmNoticeCard`
- 农场面板：`DailyFarmPreview`
- 底部导航和设置按钮：`NazhiHomeRoute`
- 问答页：`PixelChatAssetBox`
- 知识库页：`KnowledgeAssetBox`

渲染规则：

- 装饰型背景使用 `painterResource(...)`。
- 像素图拉伸时优先使用 `ContentScale.FillBounds`，但必须保证文字安全区仍有效。
- 需要保持四角和边框像素形态的面板优先使用九宫格绘制，避免整图拉伸导致边角变形。
- Canvas 绘制 PNG 时使用 `FilterQuality.None`，避免像素边缘被平滑。
- 农场 PNG 放在 `drawable-nodpi`，避免 Android 自动按密度缩放。
- 不在页面里散写一次性颜色，优先复用 `NazhiTokens` 和状态 palette。

不建议做：

- 不为每个标签单独微调文字坐标。
- 不用代码画复杂像素边框替代已经交付的 PNG 背景。
- 不把整张今日页做成固定构图背景图。
- 不让装饰图影响按钮、输入框、长文本区域的可读性。

## 8. 全页背景策略

当前不生成固定构图的整张今日页背景图。

原因：

- 今日页是可滚动页面，不同屏幕高度会改变内容位置。
- 固定大背景容易和农场、告示牌、状态入口错位。
- 后续日历、知识库、问答页也需要一致主题，不能只为今日页做孤立背景。

当前策略：

- 页面底色由主题 token 提供。
- 关键视觉由局部 PNG 承担：状态标签、农场面板、农田、告示牌、导航图标。
- 如果后续需要全页氛围，只生成轻量、可裁切、无文字、低对比的背景纹理，不生成固定布局大图。

## 9. 验收清单

新增或替换素材后，至少检查：

- [ ] 文件名与代码引用完全一致。
- [ ] PNG 尺寸符合文档。
- [ ] 透明图为 `RGBA`。
- [ ] 安全区内没有高对比装饰。
- [ ] 源目录 PNG 与 `drawable-nodpi` PNG hash 一致。
- [ ] 小屏下文字不溢出、不遮挡按钮。
- [ ] 农场缩放、拖拽、点击仍稳定。
- [ ] `:app:compileDebugKotlin` 通过。
- [ ] 条件允许时 `:app:assembleDebug` 通过。

如果只是替换 PNG，优先做视觉验收；如果改了 Compose 布局或 Canvas 变换，必须做编译验收和真机/模拟器交互检查。

## 10. 后续页面复用建议

日历页：

- 日期格按当天收纳数量分为 `0`、`1-10`、`11-25`、`26+` 四档。
- 今日日期使用 `calendar_day_today_overlay.png` 叠加高亮，不为每个数量档单独生成今日版本。
- 月历保持信息密度，不变成内容列表。
- 日期标记应像“农场年鉴”，但点击仍进入历史日期详情。

知识库页：

- 已采用局部 PNG 面板，不继续扩展为整屏固定背景。
- 搜索、详情、编辑和复制引用优先保证效率。
- 不大面积使用像素背景。

问答页：

- 引用卡片可以有轻微农场主题，但回答正文保持现代排版。
- 不使用像素字体承载长回答。

设置页：

- 只做轻量主题适配。
- API Key、服务地址、权限说明保持表单可读性。
